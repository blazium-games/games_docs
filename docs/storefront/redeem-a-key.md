# Redeem a key or gift link

Developers hand out keys and gift links for press, bundles and giveaways. Each one adds a game to your library for free.

## Redeem a key

1. Sign in, open the account menu and choose **Redeem a key**.
2. Type or paste the code into the box. Codes look like `XXXXX-XXXXX-XXXXX-XXXXX`.
3. Click **Add to my library**.

When it works, the page says "Starfall Drift is in your library." (with the game's name), and offers **Go to** the game and **Library**.

## Open a gift link

A gift link looks like `https://blazium.games/redeem/...`. Opening it fills in the code for you. Sign in if asked, then click **Add to my library**.

## Good to know

- Each code works once.
- If you already own the game, the code stays unused, so you can pass it on to someone else.
- If the page says the code was not found or was already used, check it for typos, then ask whoever gave it to you. For anything else, see [Get help](./get-help.md).
