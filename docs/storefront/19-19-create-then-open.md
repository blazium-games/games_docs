What can go wrong

New project with developer mode off only shows the sentence in picture 1. There is no form until developer mode is on.
Turn off developer mode stays as it is until you transfer or delete your projects and leave the teams you help run. The Off checkbox and Turn on developer mode are not in picture 2.
A draft is not a public page. Public is the visibility that lets other people find the project. Picture 8 is that public page, and it is Ember Racer, not Tiny Tactics.
Project URL only allows lowercase letters, numbers, dashes and underscores. The sample address in the box is not a real project URL.
Delete on the dashboard removes a project. It does not open it.
