What can go wrong

- With developer mode off, the page is only the sentence in picture 1. There is no form. The link words are Turn it on in your settings.
- Signed out, there is no New project page. The picture is the login page, and that form was not used.
- The Project URL address is a sample on localhost. The box has no placeholder.
- Name and Short description are empty. Nothing was typed.
- Project type and Status were not opened. They read Game and Release.
- On the open Visibility list, the first row repeats Draft (You And Admins). Owner Only is highlighted. It was not selected. The closed value stays Draft (You And Admins).
- Create project was not used. These pictures do not show a new project.
- Description is a label on these pictures. There is no box under it.
- The dashboard says 8 projects. This frame shows Starfall Drift, Moss Garden, and Tiny Tactics. The rest are below the frame. The button under Starfall Drift is cut off, so do not call it Edit.
- Add thumbnail and Add cover were not used.
- The account chip is on pictures 1, 2, and 3. It is not in the media, publishing, or open-menu frames.
- All analytics, the invite buttons, Edit, and the footer links are other guides.
