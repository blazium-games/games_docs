# Install the desktop app

Validated against the mock screens. Circles stay beside the controls.

The pictures are the new storefront with sample data. Pixel, Starfall Drift, and Moss Garden are samples. The corner reads Pixel on all three pictures.

1. In Your library, select Download the desktop app. That is 1, above the link, and the full link stays readable. Use the link under the circle. The sentence is Games you own on Blazium Games. Download the desktop app to install and play. It opens the desktop app page. It does not download a game. Starfall Drift has Download, Play, and Store page. Moss Garden has Download and Store page, says Free, and has no Play button. Those card buttons are for the games, not the app. The chips are All, Ready to play, Browser, Download, and In development. All is filled. They are not this guide. The header is Home, Browse, MCP, and Docs. Home does not have this link.
Picture 1 (/img/storefront/guide02-library.png): 1 is Download the desktop app. The circle is above the link.

2. The page is titled Blazium Games Desktop. It says Install, update, and launch your games library. Available for Windows and Linux. 2 is beside Start Download. The words Start Download stay readable. That starts a file download. This picture does not show the file, and there is no install wizard on the site.
3. Under the button the line says Available for Windows and Linux. 3 is under Windows. That link downloads the Windows file instead. The word Windows stays readable.
4. 4 is under Linux. That link downloads the Linux file instead. The word Linux stays readable. The lines under them say Requirements: Windows 10/11 (64-bit) or Linux (Ubuntu 20.04+, glibc 2.31+). Approximate download size: 85 MB.
5. 5 is beside Go to Library. The words stay readable. It returns to Your library.
Lower on this same picture, What's included lists Your Library, Auto-Updates, and Notifications. Your Library says Browse and launch all your purchased and free games from one place. Auto-Updates says Games update automatically in the background. Always play the latest version. Notifications says Get notified when new games launch or your favorites receive updates. For Developers says Upload builds, manage releases, and automate your workflow with the chauffeur CLI. Windows CLI, Linux CLI, macOS (Apple Silicon), and macOS (Intel) are that command-line tool, not the desktop app. They are a different guide.
Picture 2 (/img/storefront/guide02-app.png): 2 is Start Download, 3 is Windows, 4 is Linux, 5 is Go to Library.

6. On a Mac, the same page does not show Start Download or Go to Library. The title is still Blazium Games Desktop, and the line under it still says Available for Windows and Linux. A box says macOS not yet supported. The desktop app runs on Windows and Linux. 6 is beside Download for Windows. The full label stays readable. That still downloads the Windows file.
7. 7 is beside Download for Linux. The full label stays readable. That still downloads the Linux file. Lower on this picture, What's included and For Developers are the same blocks as picture 2, including the chauffeur CLI links.
Picture 3 (/img/storefront/guide02-mac.png): 6 is Download for Windows, 7 is Download for Linux.

What can go wrong

- Download on a library card downloads that game, not the desktop app. Play is only on a card that has it. Moss Garden does not have Play.
- Start Download, Windows, and Linux start a file download. The site does not show an installer after that.
- On a Mac the page does not offer a Mac app. Download for Windows and Download for Linux are the Windows and Linux files.
- The chauffeur CLI links are not the desktop app.
