# Game chat

Friend messages and each game's chat are IRC on `irc.blazium.online`. Chat follows the [Chat Rules](../legal/chat-rules.md) and is not logged.

The full guide is in the [Chat](../chat/index.md) section:

- [Chat overview](../chat/index.md): ways in, who can talk, spectating, moderation, and what chat keeps.
- [IRC clients](../chat/irc-clients.md): get a chat token from [Settings > Chat](https://blazium.games/settings/chat) and set up HexChat, WeeChat, irssi, or any IRC client (server `irc.blazium.online`, port `6697` with TLS, SASL PLAIN).
- [Commands](../chat/commands.md): `GAMEJOIN`, spectating with `LFGSUB`, `GAMES`, and what every reply means.
- [For client developers](../chat/client-developers.md): capabilities, message tags, and numerics.
- [Chat for publishers](../chat/for-publishers.md): guests, bans, and mutes for your project.
- [Troubleshooting](../chat/troubleshooting.md).
