# Get help

The [Support page](https://blazium.games/support) lists the right place for each kind of problem. It opens without signing in.

Check the [status page](https://status.blazium.games) first. If something is down, it will say so there.

| Problem | Where to go |
|---|---|
| A bug in the website, the desktop app, the MCP servers or the chauffeur CLI | Open an issue on [GitHub](https://github.com/blazium-games/support/issues). Search the open issues first. |
| Your account, a purchase or a refund | Email [support@blazium.games](mailto:support@blazium.games) from the address on your account. For a purchase, include the purchase ID from your wallet or receipt. |
| A bug in a game | Contact the game's developer. |
| Your data, or deleting your account | Email [privacy@blazium.games](mailto:privacy@blazium.games). |
| Someone breaking the [Chat Rules](../legal/chat-rules.md), or your account can't use chat | Email [support@blazium.games](mailto:support@blazium.games). See [Something in chat](./report.md#something-in-chat). |
| A leaked chat token | Regenerate it in [Settings > Chat](https://blazium.games/settings/chat). That disconnects anyone using the old one. |
| Chat won't sign in, won't let you join, or won't let you talk | See [Chat troubleshooting](../chat/troubleshooting.md). |
| A security problem | Report it privately on GitHub: [Report a vulnerability](https://github.com/blazium-games/support/security/advisories/new). If you can't use GitHub, email [support@blazium.games](mailto:support@blazium.games) with "Security" in the subject. Don't post it in a public issue. |

GitHub issues are public. Never include passwords, keys, payment details or your email address in them.

To report a game or a person that breaks the rules, see [Report a game or a person](./report.md). Refund rules are in [Refunds](../payments/refunds.md).
