# Redeem a key

Validated against the mock screens. Circles stay beside the controls.

The pictures are the new storefront with sample data. Pixel and Starfall Drift are samples. The corner reads Pixel on the redeem pictures. Starfall Drift is a sample game, not a code that was just accepted. The invalid picture and the success picture are the page's own states. They are not what happens after submitting MOCK-GIFT-1. MOCK-GIFT-1 is only the text a sample address put in the box.

1. Open the Pixel menu. Under PLAYER, select Redeem a key. That is 1, beside the row, and the words stay readable. The menu also has SITE, with Browse. Under PLAYER the other rows are Library, Friends, and Wallet. Under DEVELOPER the rows are Publish your games and MCP. Under ACCOUNT the rows are View profile, Settings, Linked accounts, and Log out. Those are other guides. Your library does not have a Redeem control. The header is Home, Browse, MCP, and Docs. The form is already visible behind this open menu. It is the empty form from the next picture. Do not fill it from this picture.
Picture 1 (/img/storefront/guide03-menu.png): 1 is Redeem a key. The circle is beside the row.

2. The page title is Redeem a code on Blazium Games. The heading is Redeem a code. 2 is beside the code box. The box has no label next to it. The placeholder is XXXXX-XXXXX-XXXXX-XXXXX, and it stays readable. Type the code there.
3. 3 is above Add to my library. The words stay readable. That submits the code.
Under the form the page says Each code works once. If you already own the game, the code stays unused so you can pass it on. Need help? goes to the support page and is a different guide. It is not numbered. The footer links are not this guide.
Picture 2 (/img/storefront/guide03-empty.png): 2 is the code box, 3 is Add to my library.

4. A link can put a code in the box before you submit. In this sample the address ends in MOCK-GIFT-1, and that text is in the box. 4 is beside the box. MOCK-GIFT-1 stays readable. It is sample text from the address, not a code this sample issued. Add to my library is the same button as 3 and is not numbered again. The help line and Need help? are the same as picture 2.
Picture 3 (/img/storefront/guide03-prefilled.png): 4 is the filled code box.

5. If the code is not accepted, the page shows Code not found or already used. 5 is beside that line, and the full line stays readable. In this sample the box still shows INVALID-CODE-12345. Add to my library is still there. This picture is that invalid state. It is not the page after submitting MOCK-GIFT-1. The help line and Need help? are still under the error.
Picture 4 (/img/storefront/guide03-invalid.png): 5 is Code not found or already used.

6. When a code is accepted, the code box is gone. The page says Starfall Drift is in your library. 6 is beside that line, and the full line stays readable. Starfall Drift is the sample game on this state. It is not a code that was just accepted.
7. 7 is beside Go to Starfall Drift. The words stay readable. In this sample that button goes to https://nova.blazium.games/starfall-drift.
8. 8 is beside Library. The word stays readable. It opens Your library.
The same help line and Need help? are still under the buttons.
Picture 5 (/img/storefront/guide03-success.png): 6 is Starfall Drift is in your library, 7 is Go to Starfall Drift, 8 is Library.

What can go wrong

- If you are signed out, opening the redeem page sends you to log in. You do not see Redeem a code. There is no signed-out redeem form. Log in is a different guide.
- Download on a library card is not redeeming a key.
- Game keys on a project page, where a developer creates keys, is guide 15, not this.
- The page does not show a separate You already own this screen. The line under the form is the note about a game you already own.
- Need help? is the support guide and is not numbered.
