What can go wrong

Open an issue and Check status were not used. Do not say an issue was opened or that status was checked.
Check status is on picture 2. It is not in the frame on pictures 1, 3, or 4. Do not copy it onto those pictures.
The lines under Privacy requests, Security reports, and Service status are cut off on pictures 1, 3, and 4. More by Blazium covers the left of the Privacy requests line. Do not quote those lines from those pictures. Picture 2 shows the full lines.
status page, status.blazium.games, and Check status are different words. Do not treat them as one control.
The support@blazium.games line in Account & payments is not the support@blazium.games line in Security reports. Same address, different cards.
The header GitHub on picture 4 is not the GitHub in the Report a bug card.
The card heading Report a bug is not the Report a bug in the Bugs in a game card.
The footer Support is not the page heading. The footer Terms of Service and Privacy Policy are not the links in the cards.
Decline and Accept are not on these pictures. They are not Open an issue or Check status.
The address bar is not in these frames. These pictures do not show a URL.
