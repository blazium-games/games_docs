# Approve an agent request

When an AI agent connected to your account through [MCP](../mcp/index.md) wants to do something important, it asks you first. You get a link to a page called **Agent request**.

1. Open the link and sign in if asked.
2. Read the line "Your agent wants to: ..." and the details under it. A purchase shows the price and the total taken from your balance. Other actions show what will happen, for example:
   - **Release to stable**: every player gets this build as the current release.
   - **Delete game**: the game page, builds and downloads go away for everyone.
   - **New deploy key**: the old deploy keys stop working, so anything using them must be updated.
   - **Create game keys**: each key gives one person the game for free.
3. Click **Approve** or **Deny**.

"Approved. Your agent can go ahead now." or "Denied. Your agent has been told no." confirms your choice.

Only approve requests you asked your agent to make.

## Good to know

- Requests expire. An expired request says "This request expired. Your agent can ask again."
- Agents only pay from your stored balance, never your card.
- Agents with wallet access can set up payouts and cash out your earnings without a request here. Money only goes to the payout account on your own account, and you get an email after each cash-out. See [Agent payouts](../payments/wallet-and-cash-out.md#agent-payouts).
- Pending requests are also listed under **Waiting for your approval** in [MCP settings](https://blazium.games/settings/mcp), where you also set how much an agent may spend without asking. See [Agent purchases](../payments/agent-purchases.md).
