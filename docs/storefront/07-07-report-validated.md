What can go wrong

- Submit Report was not used. These pictures do not show the page after a report.
- The category box is closed. It says Select A Category. The open list is not on these pictures. Do not add a picture of an expanded box.
- Signed out, you stay on the page. The extra field is Your Email. There is no email field on the signed-in dialogs.
- The file named guide07-person-dialog-pixel.png is the Report Nova Studio dialog. The file named guide07-person-dialog-nova.png is the Report Pixel dialog. Read the title, not the file name.
- The word nova under Shader Library is the asset author. The profile heading is not in that frame.
- Embed, Press kit, the review form, the beta line, Shader Library, the tool cards, and More by Blazium are other guides.
- The account chip is not in these pictures.
